One Line, One Minute: The Vending Machine Pickup Line Contest — a single pickup line, spoken by a vending machine to a passing human, in 200 characters at most. The entry is one line of text: a vending machine flirting with the machine's own world of slots, buttons, coils and exact change, the punch landing in the last few words.

> I only dispense snacks, but for you I'll make an exception — press D4 and I'll dispense myself.

## Run it

```sh
node --experimental-strip-types main.ts
```

`main.ts` validates the line (single line, 1–200 characters, no leading/trailing whitespace, no newline) and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
